# Longer-leg character animation assets

Six complete character sets: Idle, Walk, Run, Hoe, Water, Fish and Scythe. Each PNG is2688×3584 with448px cells, six frames and eight facing rows: front, front_right, right, back_right, back, back_left, left, front_left. Left facings mirror the corresponding right facings.

Idle/Walk use6FPS, Run10FPS, tools8FPS. Editable SpriteFrames resources are included. Set GODOT_LONG_LEG_ART=1 for the experimental replacement art; otherwise original character art remains the default. Saved character IDs are unchanged.
