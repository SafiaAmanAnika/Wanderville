# Local Setup (Beginner Guide)

This guide explains how to set up Wanderville on your machine for local development.

## Required Tools

- Git + Git Bash (Windows)
- Python (3.10+ recommended)
- Godot 4.x
- VS Code (or any editor)

Verify installs (optional):

```bash
git --version
python --version
```

## Clone The Repo

Run these in Git Bash (or your terminal):

```bash
git clone https://github.com/SafiaAmanAnika/Wanderville.git
cd Wanderville
git checkout authentication-and-database
git pull origin authentication-and-database
```

## Backend Setup

From the repo root, run:

```bash
cd code/server
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
cp .env.example .env
python init_db.py
pytest -q
uvicorn main:app --reload
```

Notes:

- Keep the terminal running while `uvicorn` is running.
- If activation fails on your machine, see Troubleshooting.

## Files/Folders You Must Not Commit

These are local-only artifacts and should never be pushed to GitHub:

- `.env`
- `.venv/`
- `wanderville.db`
- `test_auth.db`
- `__pycache__/`
- `.pytest_cache/`
- `.godot/`
- `.import/`

If you accidentally created/edited any of these, remove them from staging before committing.

## API Testing (Quick Checks)

With the backend running at `http://127.0.0.1:8000`, test these endpoints.

1. `GET /health`
1. `POST /auth/signup`
1. `POST /auth/login`
1. `GET /auth/me`

You can test with a browser (for `GET /health`), curl, Postman, or the autogenerated docs (usually at `http://127.0.0.1:8000/docs`).

## Godot Setup

1. Open Godot 4.
1. Click Import or Open.
1. Select the project folder: `code/client`.

Godot notes:

- Do not commit `.godot/` cache.
- Only commit project/source content such as `project.godot`, scenes, scripts, and assets.
- Do not commit `.import/`.

## Troubleshooting

### ModuleNotFoundError

- Make sure the venv is activated: `source .venv/Scripts/activate`.
- Reinstall dependencies: `pip install -r requirements.txt`.
- Confirm you are in `code/server` when running backend commands.

### .env Not Found

- Create it from the example:

```bash
cp .env.example .env
```

### Database Not Created

- Re-run initialization from `code/server`:

```bash
python init_db.py
```

- Ensure it created `wanderville.db` in the same folder.

### Username Already Taken

- Sign up with a different username, or delete/reset your local database and re-init:

```bash
# WARNING: this deletes your local data
rm -f wanderville.db
python init_db.py
```

### Port 8000 Already In Use

- Stop the process using port 8000, or run the server on another port:

```bash
uvicorn main:app --reload --port 8001
```
