# Read-only Godot integration checklist

Inspected on 2026-10-01. No client file or Godot cache was written. Backend support does not make the following features finished Godot gameplay.

| File / function | Missing mapping | Expected integration behavior |
| --- | --- | --- |
| `code/client/Scripts/farm_controller.gd`: `_till`, `_on_seed_selected`, `_water`, `_harvest` | Local tile/inventory mutations do not call authoritative farm endpoints | Call `/farm/till`, `/farm/plant`, `/farm/water`, `/farm/harvest`; apply returned plots and inventory only after success. Plant `<crop>_seed`, render returned `<crop>`, and reconcile failures without spending local resources. |
| `code/client/autoloads/GameState.gd`: `load_from_backend` | Farm reconstruction, Aura and season branches contain `pass`; every inventory item becomes a seed | Rebuild plots from `/farm/plots`; apply `aura_balance` (legacy `taka_balance` is retained), world season, and catalog/rule partitions. Distinguish seeds, produce, fish, tools, houses and rare materials. |
| `code/client/autoloads/GameState.gd`: `spend_water`, `add_water` | Local bucket defaults differ from server capacity 20 | Read `water_charges` from `/profile`, apply `water_remaining` from watering/refill; refill only after an accepted campus position near water. |
| `code/client/autoloads/APIClient.gd`: `remove_item` | No `confirmed` payload | Add explicit rare-discard confirmation; send `confirmed: true` only after user confirmation. Common discard payloads remain valid. |
| `code/client/autoloads/APIClient.gd`: `add_item`, `earn_taka`, `gain_xp` | Development award endpoints are unavailable in production | Drive purchases, sales, farming and fishing through trusted domain endpoints. Never request arbitrary currency, XP or reward grants in production. |
| `code/client/autoloads/APIClient.gd`: auth wrappers; `Global.gd`: `load_session`, `clear_session` | Refresh/logout wrappers are absent | Rotate the saved refresh token via `/auth/refresh`; submit it to `/auth/logout` and clear local state. Password changes revoke access tokens through token-version changes. |
| `code/client/Scripts/menus/login_scene.gd`: Google URL flow | Opens `/auth/google/redirect`; backend supports verified ID-token POST `/auth/google` | A separately scoped browser OAuth/redirect/deep-link integration requires Google credentials and packaging. Do not treat the existing button as a completed Google flow. |
| `code/client/autoloads/APIClient.gd`: missing profile/shop/housing/pet wrappers | New selection/preferences/pet/house state is not saved through these APIs | Use `/profile`, `/pets/actions`, `/housing/upgrade` (with current `expected_tier`), `/shop/buy` (stable request ID), `/shop/sell` and `/shop/collection`; render authoritative results. |
| `code/client/autoloads/APIClient.gd`: missing fishing wrappers | No cast/catch/drop UI contract | Use server `cast_id`, `bite_at`, `expires_at`; submit only the cast ID for catch. Render server rewards/XP and private overflow drops; expire drops after five minutes. Never choose a reward locally. |
| `code/client/autoloads/APIClient.gd`: missing social wrappers | No friends, invitations, gifts/trades or private farm views | Wire `/social/*`; only recipients accept requests/claim gifts/accept trades, senders cancel trades. Show blocked interactions and full-inventory failures without optimistic transfer. |
| `code/client/autoloads/APIClient.gd`: missing realtime transport | No first-message WS authentication, movement sequencing or snapshot interpolation | Connect `/realtime/ws`, send `{type: "auth", token: access_token}` first, then sequenced move packets. Consume snapshots, radius-filtered chat and expiring emotes; re-enter after 60-second presence expiry. Keep tokens out of URLs. |
| `code/client/autoloads/APIClient.gd`: missing progression/notification/event wrappers | No inbox, goals or event claim mapping | Read `/progression/goals`, `/progression/statistics`, `/notifications`, `/events`; render server awards and replay failures. Awards are generated in trusted gameplay transactions. |
| `code/client/autoloads/APIClient.gd`: missing tutorial/feedback/report/delete wrappers | No ordered tutorial, one-time hints, bounded private reports or reauthentication | Wire documented profile/social requests, including username confirmation plus password or a verified matching Google identity before deletion. |

Visual pet following, remote interpolation, fishing effects, house placement, seasons, sounds, overlays and new screens remain client work. The backend polygon snapshot covers known campus regions, not all TileSet/building physics. Original external SRS CSV/design PDF files were not present in this checkout; the supplied audit/design interpretation was reviewed.
